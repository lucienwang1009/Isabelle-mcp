# M5 — Ergonomics & Ship Implementation Plan

**Goal:** Cut the first public `0.1`: a reproducible end-to-end proof harness,
Docker packaging, polished docs/SKILL, and a version bump.

**Builds on M1–M4.** No submodule changes.

## Scope & honest deferrals

The design spec's E2E is a "scripted Claude/GPT session." This repo's CI cannot
drive a real LLM, so M5 ships a **deterministic auto-prover** that exercises the
*entire* MCP tool stack (open → step → try0 → sledgehammer → apply) over a set
of fixture lemmas and asserts ≥7/10 close. This is reproducible and gates
regressions without an API key. A real-LLM transcript suite remains future work.

Also deferred (out of this environment's control): upstream PRs to AutoCorrode
(stdio transport, try0) — tracked as follow-ups, not blockers for `0.1`.

## Tasks

### Task 1: E2E auto-prover
- `scripts/e2e_autoprove.py`: for each fixture lemma, open a REPL on `Main`,
  state the goal, try `isabelle_try0`; if no tactic, `isabelle_sledgehammer`;
  apply the discovered one-liner with `isabelle_step`; record closed/now.
  Print a table and exit 0 iff ≥ threshold (default 7) closed.
- `tests/integration/test_e2e.py` (mark `heavy`): run the harness in-process
  over ~10 lemmas (Nat arithmetic, list induction-free, set algebra) and assert
  ≥7/10 close through the MCP tool layer.

### Task 2: Docker
- `Dockerfile`: from a slim base, install Isabelle2025-2, build the HOL heap,
  copy the repo (with submodule), `uv sync`, default `CMD` runs `isabelle-mcp`.
- `.dockerignore`. Documented as **not** built in CI here (the image is multi-GB
  due to Isabelle); provided for users.

### Task 3: Version bump, polish, ship
- `pyproject.toml` → `version = "0.1.0"`, Development Status :: 4 - Beta;
  `__version__` to match.
- README: status `0.1`, architecture/tool summary current; SKILL final pass.
- Run full `uv run pytest`; tag `v0.1.0`; push.

## Acceptance criteria
1. `uv run pytest` green (incl. the heavy E2E with Isabelle present).
2. `scripts/e2e_autoprove.py` closes ≥7/10 fixture lemmas and exits 0.
3. `Dockerfile` present and lint-clean (hadolint-style sanity), version is
   `0.1.0`.
4. Tag `v0.1.0` on the remote.
